# 12주차 성적 데이터 분석

## 언제, 누가

- **언제:** 2026년 11월 22일 (저장소의 최초 커밋 기준)
- **누가:** Lee Woongyong이 실습을 진행하고, Copilot의 도움을 받아 코드를 작성했습니다.

## 무엇을, 왜

실습용 학생 성적 CSV를 정제하고 분석하는 프로젝트입니다. 잘못되거나 중복된 데이터를 처리한 뒤 필터링, 그룹화, 통계 계산과 테스트를 연습하기 위해 만들었습니다.

입력 데이터는 학번, 이름, 반, 과목, 점수의 다섯 열로 구성됩니다. `scores_2026.csv`는 114행이며 정제 후 100행이 남습니다.

## 어떻게

1. `정제(df)`는 원본을 복사하고 점수 결측 행 삭제, 완전히 같은 행 중복 제거, 반과 과목의 앞뒤 공백 제거, 0~100 범위 밖 점수 삭제를 순서대로 수행합니다. 각 단계의 행 수를 출력합니다.
2. 정제된 데이터에서 수학 행과 1반의 90점 이상 행을 필터링합니다.
3. 반별, 과목과 반별 점수 평균을 구합니다.
4. `반별평균(df)`는 반별 점수 개수·평균·중앙값·최댓값을 소수 둘째 자리까지 반올림해 출력하고, 반별 평균을 Series로 반환합니다.
5. pytest로 정제 결과와 점수 합계, 작은 데이터의 평균을 검증합니다.

## 실행 방법

프로젝트 폴더에서 Python과 필요한 패키지를 준비한 뒤 실행합니다.

```powershell
python -m pip install pandas pytest
python analysis.py
```

테스트 실행:

```powershell
python -m pytest -q test_analysis.py
```

## 파일

- `analysis.py`: 정제, 필터링, 그룹화 및 통계 분석
- `test_analysis.py`: 네 가지 결과를 확인하는 테스트
- `scores_2026.csv`: UTF-8 실습 데이터
- `scores_2026_cp949.csv`: 같은 데이터의 CP949 인코딩 파일
- `mini.csv`: 손계산과 테스트에 사용하는 작은 데이터
- `README_데이터.md`: 데이터 구성 및 정제 결과 안내
- `prompts.txt`: 실습에 사용한 프롬프트
